**指令界面**  
![配置界面](/img/latest/MacroCMD/IfPro.png)

### 功能说明
自上而下执行满意第一个条件的分支指令，若都不满足则执行"以上都不是"分支指令

### 分支右键菜单
1. **编辑**：打开新窗口编辑分支的条件，分支指令
2. **向上插入分支**：对应位置插入新的分支
3. **向下下入分支**：对应位置插入新的分支
4. **向上移动**：分支位置上移，优先级增加
5. **向下移动**：分支位置下移，优先级降低
6. **删除**：删除对应分支
