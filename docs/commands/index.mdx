本节逐条说明宏指令的功能、参数与执行行为。每条指令的页面结构基本一致：功能说明 → 特别说明 → 参数解析 → 指令格式。

**输入与基础**

| 指令 | 用途 |
|------|------|
| [1 间隔](./interval.mdx) | 在指令之间加入延时，或设置宏的循环间隔 |
| [2 按键](./key.mdx) | 按下、松开、点击按键 |
| [3 搜索](./search.mdx) | 在屏幕上搜索图片、颜色或文本 |
| [4 搜索Pro](./search-pro.mdx) | 搜索指令的完整版，支持结果保存与目标点保存 |
| [5 移动](./move.mdx) | 鼠标移动到指定坐标 |
| [6 移动Pro](./move-pro.mdx) | 移动指令的完整版，支持相对位移与游戏视角 |
| [7 输入](./input.mdx) | 弹窗或按钮输入变量值，控制宏暂停与继续 |
| [8 输出](./output.mdx) | 以指定形式输出信息 |
| [9 循环](./loop.mdx) | 多次执行循环体中的指令 |
| [10 宏操作](./macro-op.mdx) | 插入、触发、暂停、终止其他宏 |

**变量与逻辑**

| 指令 | 用途 |
|------|------|
| [11 变量](./variable.mdx) | 创建变量，获取系统变量 |
| [12 变量提取](./variable-extract.mdx) | 从屏幕、剪切板、窗口中提取数值或文本 |
| [13 如果](./if.mdx) | 按逻辑判断结果执行分支指令 |
| [14 如果Pro](./if-pro.mdx) | 多条件的逻辑分支 |
| [15 运算](./operation.mdx) | 用运算表达式计算并保存结果 |
| [18 文本处理](./text-ops.mdx) | 文本分割、提取、替换、去空格、大小写转换与统计 |
| [19 数组](./array.mdx) | 数组的创建、取值、插入、追加、移除、反转 |

**系统与后台**

| 指令 | 用途 |
|------|------|
| [16 运行](./run.mdx) | 运行文件、进程、脚本，访问网址 |
| [17 文件读写](./file-io.mdx) | 读写文本文件与 Excel |
| [20 RMT指令](./rmt-cmd.mdx) | 调用软件自身指令或操作系统指令 |
| [21 后台鼠标](./bg-mouse.mdx) | 对指定窗口后台操作鼠标，不影响真实键鼠 |
| [22 后台按键](./bg-key.mdx) | 对指定窗口后台操作按键，不影响真实键鼠 |
| [23 窗口管理](./window-manage.mdx) | 激活、移动、缩放、置顶、改标题、设透明度 |
| [24 按键检测](./key-check.mdx) | 检测单个或多个按键的物理/逻辑状态 |
| [25 注释](./remark.mdx) | 给指令添加备注，没有任何实际效果 |
