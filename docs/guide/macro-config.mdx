用于定义单条宏的触发方式与执行行为：

| 参数 | 说明 |
|------|------|
| 📝 **宏名称** | 对宏用途进行说明，便于管理与维护。 |
| ⌨️ **触发键编辑** | 打开触发键设置界面，进行可视化配置。 |
| 🖼️ **触发键编辑（菜单宏 / 界面宏）** | 打开扇区或界面按钮上的图标设置。 |
| ⏰ **触发键编辑（定时）** | 打开定时设置界面。 |
| 🎯 **触发类型** | 设置宏的触发按键与方式：<br/>• **按下**：按下即触发，未松开可重复触发<br/>• **松开**：松开时触发<br/>• **松止**：按下持续触发，松开后终止<br/>• **开关**：首次触发开始，再次触发终止<br/>• **长按**：持续按下到指定时间后触发<br/>• **双击**：双击触发键后触发 |
| 🔁 **循环次数** | 设置宏的重复执行次数（可下拉选择「无限」）。 |
| 🎹 **宏设置 · 按键类型** | • **AHK Send**：通用方式，适合办公软件与大多数游戏（管理员权限可让更多游戏有效）<br/>• **keybd_event**：系统接口方式，适合老软件或游戏（需管理员权限）<br/>• **罗技**：调用罗技驱动模拟按键（需管理员权限，并使用 G HUB 2022.2.1154 及以前版本）<br/>• **AHI**：调用 Interception 驱动模拟按键（需管理员权限，并安装 Interception）<br/>⚠️ *keybd_event、罗技和 AHI 的按键可作为宏的触发按键，切勿自己触发自己导致死循环* |
| 🔊 **宏设置 · 开始提示音** | • **无**：不播放提示音<br/>• **触发提示**：触发时提示，循环触发会多次提示<br/>• **循环首次提示**：触发时提示，循环触发不再提示 |
| 🔊 **宏设置 · 结束提示音** | • **无**：不播放提示音<br/>• **结束提示**：宏结束时提示，循环多次结束就多次提示<br/>• **循环结束提示**：结束时提示，循环结束不再多次提示 |
| ✏️ **宏指令编辑** | 打开宏指令编辑器，编辑宏内容。 |
| 📋 **复制** | 复制当前宏内容，可在模块上粘贴使用。 |
| 🚫 **禁用** | 禁用当前宏配置，不参与触发与执行。 |
| 🗑️ **删除** | 删除当前宏配置（不可恢复）。 |
