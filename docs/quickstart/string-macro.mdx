**功能说明**：
- 当按下一系列设定的字串时，触发宏。
- 例如输入 `wasd、word、aa、aaaa`等等字串
- 字串宏和按键宏的区别是：字串宏根据输入的字串触发，按键宏根据按键状态触发

**操作步骤**：
1. 选择字串宏页签: 主界面下点击切换到`字串宏`页签。
2. 添加新宏: 点击字串宏模块顶部`新增宏`按钮。
3. 设置触发按键：点击`触发键`按钮，新窗口点击两次`按钮A`。
![最终按键配置界面](/img/latest/Quickly/StrTriggerSet.png)
***图示：字串宏触发键配置界面***

4. 设置宏指令：点击 `宏指令`按钮 → 指令选项中点击 `运行` → 路径下输入`notepad.exe` → 点击编辑界面`确定`按钮 → 点击宏指令编辑界面`确定`按钮。
![最终按键配置界面](/img/latest/Quickly/RunSet.png) 
***图示：运行指令配置界面***

5. 点击主界面左下角`应用并保存`按钮即可。

**配置效果**：当双击`按键A`,软件辅助打开notepad.exe
