# RMT 使用文档

RMT（若梦兔）是 Windows 下的键鼠宏工具：按键宏、字串宏、菜单宏、界面宏、定时宏，配合图像识别、颜色搜索、OCR 文本识别等指令，把重复操作交给软件完成。

- **[软件介绍](./guide/index.mdx)**：名词、页签、宏模块与各项配置的含义
- **[快速上手](./quickstart/index.mdx)**：从零做出第一个宏的 10 个例子
- **[指令手册](./commands/index.mdx)**：逐条指令的参数、行为与截图
- **[常见问题](./faq/index.mdx)** / **[常见报错](./errors/index.mdx)**
- **[更新日志](./changelog/index.mdx)**
- **[开发指南](./dev/index.mdx)**：参与开发前的代码结构说明

:::tip 选版本

导航栏右上角的版本下拉可以切到历史版本（1.2.2 / 1.1.2）。你正在看的是开发中的最新版，与软件实际版本可能有出入，按自己的软件版本切换即可。

:::
