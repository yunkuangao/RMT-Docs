### `MacroEditGui.ahk`
**功能概述：**
主宏编辑器，支持用户自定义宏逻辑。

**职责内容：**
- 编辑界面的布局与控件初始化
- 支持多步骤宏指令添加/插入/删除等
- 提供"录制按键"、"调试"等便捷功能
- 各类指令的按钮入口

### 流程图编辑器 (`MacroGraph/`)
**功能概述：**
可视化流程图宏编辑与执行模块，包含 12 个文件：

| 文件 | 职责 |
|------|------|
| `MacroGraphGui.ahk` | 主界面 |
| `MacroGraphData.ahk` | 数据结构 |
| `MacroGraphNodeUI.ahk` | 节点 UI 渲染 |
| `MacroGraphConnections.ahk` | 连线管理 |
| `MacroGraphEvents.ahk` | 事件处理 |
| `MacroGraphFormal.ahk` | 格式化/布局 |
| `MacroGraphFormalHandlers.ahk` | 格式化事件处理 |
| `MacroGraphHandlers.ahk` | 通用事件处理 |
| `MacroGraphEdit.ahk` | 编辑功能 |
| `MacroGraphBranch.ahk` | 分支逻辑 |
| `MacroGraphIfPro.ahk` | 条件判断节点 |
| `MacroGraphMenu.ahk` | 右键菜单 |
