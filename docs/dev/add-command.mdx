---
title: "🆕 新指令添加流程（以\"开源\"指令 OpenSource 为例）"
sidebar_position: 10
---
如果你想新增指令，请参考以下流程：

1. **新增数据保存文件路径**  
   在 `AssetUtil.ahk` 的 `InitFilePath` 函数中添加：  
   ```ahk
   global OpenSourceFile := A_WorkingDir "\Setting\OpenSourceSettings.ini"
   ```

2. **定义指令数据结构**  
   在 `DataClass.ahk` 中新增结构体 `OpenSourceData`，类似已有的 `RunData`。  
   重点字段：  
   - `SerialStr` — 指令序列化标识，必须唯一，用于区分不同指令。  
   - 其他参数根据指令需求定义。

3. **新增指令编辑界面**  
   - 复制现有的 `Gui/RunGui.ahk`，重命名为 `Gui/OpenSourceGui.ahk`。  
   - `GetCMDSerialStr("运行")` 改成 `GetCMDSerialStr("开源")`
   - 根据指令参数调整 `AddGui()` 和相关接口，确保界面能编辑对应参数。

4. **添加指令按钮入口**  
   - 在 `Gui/MacroEditGui.ahk` 中新增按钮，调用 `OpenSourceGui.ahk` 以打开编辑界面。  
   - 参考已有"文件"按钮实现。

5. **实现指令执行逻辑**  
   - 在 `Main/Util/MacroUtil.ahk` 的 `ExecuteMacroCmdOnce()` 中添加 `Actions` 映射：  
     ```ahk
     "开源", OnOpenSource,
     ```
   - 实现 `OnOpenSource()` 函数，复杂指令参考"按键"指令，简单指令参考"文件"指令。
