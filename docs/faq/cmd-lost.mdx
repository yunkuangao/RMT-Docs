---
title: "指令丢失"
sidebar_position: 8
---
宏指令执行过于紧凑时，可能会导致部分指令未被系统识别或执行。
原因： 系统处理指令需要时间，若指令之间没有合理间隔，后续指令可能被丢弃。
### 解决方法
在指令之间增加适当的**间隔**，可以有效提升宏执行的稳定性。
### 推荐建议
| 场景 | 推荐值/做法 |
|------|-------------|
| 宏按键点击时长（按下到松开） | 推荐 **100ms** |
| 宏按键点击时长（最低不建议） | 低于 **30ms** 易丢失 |
| 搜索按钮点击操作（不影响功能前提下） | 后续增加 **500ms** 或更多间隔，避免按钮响应慢，影响后续指令 |
| 宏末尾（不影响功能前提下） | 增加 **200ms** 间隔，有助于避免状态异常 |
| 通用习惯 | 不追求极限速度时，多插入**100ms**间隔是良好的习惯 |
> 提示：适当增加间隔不会明显影响使用体验，但能显著提高宏的可靠性。
