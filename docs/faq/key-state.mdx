### 基本规则
- 宏配置结束后，请确保所有宏按键都已**松开**，否则可能导致配置失效或按键卡住（除非刻意需要保持按下状态）。
- 宏按键的「点击」操作，实际由三个指令组合而成：**按下 → 间隔（点击时长）→ 松开**。

### 点击时长与表现
| 点击时长 | 表现 |
|---------|------|
| ≤ 250ms | 点击操作 |
| 250ms ~ 500ms | 因不同软件、游戏而有所差异 |
| ≥ 500ms | 长按操作 |

### 重复按下
宏按键「按下后未松开又再次按下」的行为，可在软件设置中配置处理方式。

> 真实键盘无法触发此行为（通常无效）；部分按键检测网站可能检测不到，但记事本中可正常输出。

### 随机间隔
设置界面「数值选项」中可配置以下随机浮动：

- **点击时间浮动**：宏按键点击时长的随机浮动
- **每次间隔浮动**：宏按键多次点击时，每次间隔的随机浮动
