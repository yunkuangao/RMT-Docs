| [部分宏按键无效](./partial-key-invalid.mdx) | 左键、右键、回车等按键失效 |
| [配置突然失效](./suddenly-invalid.mdx) | 之前好用，忽然不再触发 |
| [罗技键鼠无效](./logitech.mdx) | 按键类型选「罗技」时失效 |
| [指令丢失](./cmd-lost.mdx) | 宏执行太快，部分指令没生效 |
| [宏按键说明](./key-state.mdx) | 点击时长、重复按下、随机间隔等机制说明 |
