### 编译 Work.ahk
如果调整会对 `Work.ahk` 有影响，需要先重新编译：
如果重新编译觉得麻烦，也可以临时把多线程改成0

1. **清理旧文件**  
   删除 `Thread` 目录下所有的 `.exe` 文件。

2. **打开编译工具**  
   通过 `AutoHotkey Dash` → 选择 `Compile`。

3. **选择源文件**  
   - **Source**：选择 `Thread\Work.ahk` 文件。

4. **设置输出路径**  
   - **Destination**：设置为 `Thread` 目录下的 `Work1.exe`。

### 运行 RMT.ahk
直接双击 `RMT.ahk` 文件即可运行。
