title: "6️⃣. 定时宏（指定时间触发）"
sidebar_position: 7
---
**功能说明**：当到达指定时间时，触发宏。

**操作步骤**：

1. 选择定时宏页签: 主界面下点击`定时宏`页签。
2. 添加新宏: 点击定时宏模块顶部`新增宏`按钮。
3. 设置触发按键：点击`定时`按钮，新窗口`开始时间`设置成当前时间+2分钟。
![最终按键配置界面](/img/1.1.2/Quickly/TimingSet.png)
***图示：定时宏时间配置界面***

4. 设置宏指令：点击 `宏指令`按钮 → 指令选项中点击 `输出` → 输出方法拉取选取`软件弹窗` → 点击编辑界面`确定`按钮 → 点击宏指令编辑界面`确定`按钮。
![最终按键配置界面](/img/1.1.2/Quickly/TimingOutputSet.png) 
***图示：输出指令配置界面***

5. 点击主界面左下角`应用并保存`按钮即可。

**配置效果**：当到达设置时间时,软件弹窗显示指定文本内容
