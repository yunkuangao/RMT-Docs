### 功能说明
对文本文件、Excel读取或写入内容

### 操作类型
1. 读取Excel
  - 单元格：读取指定单元格内容
  - 指定行：读取指定单元格右侧的所有表格内容
  - 指定列：读取指定单元格下方的所有表格内容
  - 指定区域-行：逐行读取指定区域所有表格
  - 指定区域-列：逐列读取指定区域所有表格
2. 写入Excel
  - 单元格：把输出内容写入特定单元格
  - 行号自增：把输出内容写入指定单元格右侧第一个空表格中
  - 列号自增：把输出内容写入指定单元格下方第一个空表格中
  - 指定区域-行：把数组写入指定单元格右下方区域（一维数组时：写入一行）
  - 指定区域-列：把数组写入指定单元格右下方区域（一维数组时：写入一列）
3. 读取文本文件
  - 读取全部内容：读取文本文件中所有的文本
  - 逐行读取：从指定行开始逐行读取文本文件的内容
  - 指定行：读取文本文件指定行中的内容
4. 写入文本文件：
  - 覆盖写入：清空文本文件所有内容，然后写入内容
  - 追加写入：文本文件中末尾追加写入内容
  - 追加写入-行: 文本文件末尾添加回车后写入内容
  - 指定行：替换指定行的内容
  - 行号自增：有空行内容时替换空行，否则末尾`追加写入-行`

### 特别说明
1. 如果Excel表格写入时表格没打开，写入速度特别慢。已打开写入速度比较快。
2. 表名或序号：此处输入要写入的表格名称或者表格在所有表格中的序号（从1开始）
