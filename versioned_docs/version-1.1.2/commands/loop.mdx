### 功能说明
多次执行循环体中的指令

### 基本参数
**循环次数**：循环体将要执行的次数
**循环条件**：满足条件时继续循环或退出循环
**逻辑关系**：条件之间的逻辑关系
**循环体**：多个指令组合，每次循环时执行

### 循环条件
**无**：按循环次数执行循环体
**继续条件**：按循环次数执行循环体，每次执行循环体判断条件是否符合，符合条件才执行循环体
**退出条件**：按循环次数执行循环体，每次执行循环体判断条件是否符合，符合条件时退出循环
