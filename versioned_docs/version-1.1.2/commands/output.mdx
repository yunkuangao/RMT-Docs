**指令界面**  
![配置界面](/img/1.1.2/MacroCMD/Output.png)  

### 功能说明
以指定的形式输出信息

### 输出类型
1. **发送内容**：使用AHK的SendText指令发送内容。
2. **粘贴内容**：使用Ctrl+V组合键粘贴内容。
3. **临时提示**：使用ToolTip在鼠标指针旁显示内容（默认显示5s）。
4. **指令窗口**：将内容输出到指令显示窗口。
5. **软件弹窗**：通过软件弹窗显示内容。
6. **系统语音**：通过语音播输出内容。
7. **复制到剪切板**：将输出内容复制到剪切板。

### 输出内容特别说明
- \{var}：执行时将变量var的值替换内容中的\{var}
- \{εArr}：执行时将数组Arr的值替换内容中的\{εArr}
