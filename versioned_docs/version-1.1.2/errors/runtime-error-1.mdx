软件目录下Plugins的Dll被锁定

![问题截图](/img/1.1.2/Question/DLLLock.png) 

**解决方法：**

- Plugins/IbInputSimulator.dll文件右键->属性->解除锁定
- Plugins/RMT/RMT.dll文件右键->属性->解除锁定
- Plugins/ViGEm/ViGEmWrapper.dll文件右键->属性->解除锁定
- Plugins/RapidOcr/RapidOcrOnnx.dll文件右键->属性->解除锁定
- Plugins/OpenCV/RMT_OpenCV.dll文件右键->属性->解除锁定
- Plugins/OpenCV/opencv_world481.dll文件右键->属性->解除锁定
![关键截图](/img/1.1.2/Question/DLLLockAns.png)
