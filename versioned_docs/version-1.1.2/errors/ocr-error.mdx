RapidOcrOnnx库文件加载失败：

![文本识别加载失败示意图](/img/1.1.2/Question/RapidOCRLoad.jpg)  
![文本识别加载失败示意图](/img/1.1.2/Question/RapidOCRLoad2.jpg)  

**解决方法：**
1. 位数不匹配
- 若电脑是64位机器，请下载64位若梦兔版本软件
- 若电脑是32位机器，请下载32位若梦兔版本软件
- 若不清楚自己电脑位数，下载64位若梦兔版本软件

2. 缺少DLL运行库
    - 下载并安装运行库：[Microsoft VC++ 运行库下载链接](https://learn.microsoft.com/zh-cn/cpp/windows/latest-supported-vc-redist?view=msvc-170)
    - 加入软件交流群，下载并运行群文件中的dll补丁程序
    （若上诉操作均未解决问题，请在网络上下载dll，若使用其他dll库解决，请反馈到社区）
