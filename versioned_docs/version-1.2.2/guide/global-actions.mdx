title: "🌐 全局操作"
sidebar_position: 2
---
全局操作用于控制软件整体运行状态：

| 功能 | 说明 |
|------|------|
| 🌙 **休眠** | 立即终止所有宏，并禁用软件全部功能；取消休眠后恢复运行。 |
| ⏸️ **暂停** | 暂停当前所有宏，再次点击继续执行。 |
| ⛔ **终止所有宏** | 强制停止所有正在运行的宏任务，**不可恢复**，用于紧急情况。 |
| 🔄 **重载** | 重新加载当前配置，撤销未保存的修改（图形节点编辑器中的修改不会撤销）。 |
| 💾 **应用并保存** | 保存并立即应用所有修改；未点击前，修改的配置不会生效。 |
