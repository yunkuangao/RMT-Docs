对配置进行分类管理：

| 参数 | 说明 |
|------|------|
| 📥 **迁入配置文件夹** | 选择旧版本或同版本若梦兔（假定叫 A）的 `Setting` 文件夹，把 A 中所有配置覆盖同步到当前软件。<br/>⚠️ *当前软件的所有配置会自动备份到 `SettingOld` 目录下* |
| ✏️ **重命名** | 修改当前配置名称。 |
| 🔧 **配置校准** | 迁入或重命名后若配置异常，可尝试使用该功能修复。 |
| ➕ **新增配置** | 新增一个配置。 |
| 📦 **导入配置** | 选择一个 `.rmt` 文件导入配置（共享仓库可下载）。 |
| 🔀 **合并导入** | 选择一个 `.rmt` 文件或本地已有的配置，合并到当前配置中。 |
| 📂 **加载配置** | 切换到选中的配置。 |
| 🗑️ **删除配置** | 删除选中的配置。 |
| 📄 **使用说明** | 共享仓库的配置要求必须填写；导入的 `.rmt` 文件配置可以查看说明。 |
| 📤 **导出配置** | 将选中的配置导出为 `.rmt` 文件，可共享上传、方便配置分享。 |
| 🌐 **打开仓库** | 打开共享仓库，可以下载学习案例，或他人已经共享的游戏相关配置。 |
| ☁️ **共享上传** | 选择本地的 `.rmt` 文件上传到服务器，经过审核后同步到共享仓库中。 |
