用于调节整体行为与模拟真实性的全局参数：

| 设置项 | 说明 |
|--------|------|
| ⏱️ **点击时间浮动（%）** | 按键点击时间的浮动范围。例如：设为 10，原 50ms → 最终约 45～55ms。 |
| ⏳ **每次间隔浮动（%）** | 多次点击、多次搜索、多次提取间隔浮动范围。例如：设为 10，原 500ms → 实际约 450～550ms。 |
| ⌛ **间隔指令浮动（%）** | 间隔指令的浮动范围。例如：设为 10，原 3000ms → 实际约 2700～3300ms。 |
| ↔️ **坐标 X 浮动（px）** | 模拟点击时 X 坐标的浮动范围。例如：设为 30，原 X=900 → 实际约 870～930。 |
| ↕️ **坐标 Y 浮动（px）** | 模拟点击时 Y 坐标的浮动范围。例如：设为 50，原 Y=400 → 实际约 350～450。 |
| 🧵 **多线程数（-1～10）** | `-1`：动态多线程；`0`：单线程；`n`：多线程固定为 n。 |
| ⚡ **开机自启** | 开机时自动运行软件。 |
| 🛡️ **管理员启动** | 软件运行后提权为管理员。 |
| ⌨️ **自动松开修饰键** | 修饰键 + 普通键触发宏时，自动松开修饰键。 |
| 🔁 **连续触发** | 按下、开关、长按可以按住连续触发。 |
| 💬 **无变量提醒** | 当使用不存在的变量时弹窗提示。 |
| 🪟 **模态子窗口** | 只有关闭子窗口才能操作主窗口。 |
| 🌐 **语言 / Lang** | 设置软件显示语言。 |
| 🔤 **软件字体** | 设置界面字体。 |
| 🧩 **首选编辑器** | 设置宏内容为空时打开的编辑器类型。 |
| 📸 **截图方式** | 设置截图实现方式；当截图报错时请切换其他截图方式。 |
| 🎮 **手柄类型** | 设置手柄宏的按键类型。 |
| ⌨️ **按下时按下** | 宏按键按下后再次按下时的特殊调整选项。 |
| 🎨 **主题** | 配置软件所有的颜色配比。 |
| ⌨️ **快捷键** | 修改软件所有的快捷按键。 |
| ⏺️ **指令录制** | 设置指令录制时的一些录制细节。 |
| 🎡 **轮盘** | 设置菜单轮盘大小、触发方式、显示位置。 |
| 🪟 **界面浮窗** | 设置界面宏的默认位置、大小等。 |
| 📺 **指令显示** | 设置宏执行时的内容显示位置等。 |
