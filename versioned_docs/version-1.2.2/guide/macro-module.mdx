title: "📦 宏模块"
sidebar_position: 4
---
对宏进行分类管理：

| 参数 | 说明 |
|------|------|
| 📝 **备注** | 对模块进行说明，便于后续管理与维护。 |
| 🪟 **前台** | 模块下所有配置只在设定的窗口中触发；置空则在所有窗口皆可触发。 |
| ➕ **新增宏** | 在模块最下方增加一条宏配置。 |
| 📋 **粘贴宏** | 需先点击宏配置中的「复制」，再点击「粘贴」，可将复制的宏内容添加到新增宏配置中。 |
| 📁 **新增模块** | 在当前模块下方新增一个模块。 |
| 🗑️ **删除模块** | 删除当前模块（不可恢复）。 |
| 🚫 **禁用（模块）** | 禁用当前模块下所有宏配置的手动触发（仍可通过宏操作调用触发）。 |
| 📋 **复制** | 复制当前宏内容，可在模块上粘贴使用。 |
| 🚫 **禁用（宏）** | 禁用当前宏配置，不参与触发与执行。 |
| 🗑️ **删除** | 删除当前宏配置（不可恢复）。 |
| ⌨️ **菜单触发键** | 配置当前模块菜单轮盘的触发按键。 |
| 🪟 **面板触发键** | 配置当前模块界面浮窗的控制开关。 |
