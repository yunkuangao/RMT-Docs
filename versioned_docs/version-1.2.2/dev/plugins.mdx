---
title: "🔌 插件 (`Plugins/`)"
sidebar_position: 7
---
| 插件 | 能力 |
|------|------|
| `OpenCV/` | 图片识别（模板匹配、特征检测），含 x64/x86 版本 DLL |
| `RapidOcr/` | 文字识别（OCR），支持中文/英文模型 |
| `ViGEm/` | 虚拟手柄模拟（通过 ViGEmBus 驱动模拟 Xbox/DS4） |
| `AhiDriver/` | 虚拟输入驱动 |
| `ScreenCapture/` | 屏幕截图工具（独立 exe 进程） |
| `AHK-XAML/` | XAML/WPF UI 渲染库 |
| `IbInputSimulator.ahk` + `.dll` | 输入模拟库 |
| `MouseControl.ahk` + `.dll` | 鼠标控制库 |
| `CLR.ahk` | .NET CLR 宿主，支持调用 C# 代码 |
| `RMT/` | C# 辅助库（RMT.dll, Device.cs, Http.cs） |
