| 目录 | 说明 |
|------|------|
| `Audio/` | 提示音（Start.wav, End.wav） |
| `Images/` | 图片资源（FreePaste, Gif, ScreenShot, Soft） |
| `Setting/` | 用户配置文件（MainSettings.ini, themes.ini） |
| `MinTool/` | 小工具（CountDown 倒计时, PlayAudio 音频播放） |
| `Log/` | 运行时日志 |
| `Web/` | 文档（开发指南、指令手册、更新日志、常见问题等） |
| `ReleaseX64/` / `ReleaseX86/` | 发布版本资源 |
| `Joy/` | 手柄驱动与按键映射图片 |
