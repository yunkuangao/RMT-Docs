### `RMT.ahk`
程序的主入口，负责初始化与启动。

**初始化流程：**
1. `SelfCheckMissingFiles()` — 文件完整性自检（开发阶段注释掉）
2. `InitFilePath()` — 初始化文件路径（配置文件、日志等）
3. `LoadCurMacroSetting()` — 加载用户配置文件
4. `HandleOpenArg()` — 处理打开软件的参数
5. `EditListen()` — 滚轮按键监听
6. `InitData()` — 初始化软件内部数据缓存
7. `InitUI()` — 初始化主界面 UI
8. `SetEditData()` — 缓存编辑器数据
9. `PluginInit()` — 初始化插件（耗时较长，放后面）
10. `TimingCheck()` — 轮询检测定时触发
11. `BindKey()` — 绑定全局快捷键
