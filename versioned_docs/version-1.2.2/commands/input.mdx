**指令界面**  
![配置界面](/img/1.2.2/MacroCMD/Input.png)

## 功能说明
1. 弹窗或按钮输入变量值
2. 控制宏暂停&继续的指令

## 类型
1. 弹窗：弹窗输入变量值
2. 状态：通过真假按钮输入 真值为1，假值为0
3. 继续：点击按钮以继续宏指令
4. 继续&取消：继续或终止宏指令

## 交互时
1. 暂停当前宏：输入交互时暂停当前执行的宏
2. 暂停所有宏：输入交互时暂停所有执行的宏

## 取消时
1. 终止当前宏：点击取消按钮时 终止当前宏
2. 终止所有宏：点击取消按钮时 终止所有宏

## 特别说明
1. 交互时：回车键默认为真值或继续
2. 交互时：ESC键默认为假值或取消
