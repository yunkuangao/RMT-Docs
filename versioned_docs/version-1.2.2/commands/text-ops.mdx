## 功能说明
对文本或变量进行处理（分割，提取，替换，去空格，大小写转换，统计等）

## 处理类型
1. 文本分割：按文本内容或固定长度分割源文本
2. 文本提取：提取源文本中的数字，单词，中文
3. 文本替换：替换源文本中的内容
4. 去除空格：按类型去除前、后或所有的空格
5. 大小写转换：源文本中的大小写按类型调整
6. 文本统计：统计源文本中字符数、单词数、行数

## 类型参数
1. 分割文本： 根据分割文本对源文本进行分割
2. 定长分割： 源文本分割成固定长度的文本段
3. 查找文本： 源文本中需要替换的文本
4. 替换文本： 源文本中查找文本替换成该文本
